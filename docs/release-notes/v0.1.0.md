# Observatory 0.1.0

First public version of Observatory, a local-first Docker monitoring and test investigation tool for individual developers and small teams. MIT licensed.

## Included

- Container inventory and CPU, memory, network/block I/O and PID history.
- Compose project filtering and recorded lifecycle/health events.
- Bounded, on-demand Docker log snapshots with search, stream filtering and copy.
- Named test sessions, resource/event summaries and completed-session comparison.
- Per-project opt-in local alerts with dismissal and investigation links.
- React/TypeScript dashboard with light/dark themes and container detail panels.

## Install

Download `observatory-0.1.0.zip` and `SHA256SUMS` from this release. Extract the ZIP, follow `INSTALL.md`, copy `.env.example` to `.env` and set a unique database password before starting. Run `docker compose pull`, then `docker compose up -d`; open http://localhost:8080. Docker/Compose is required; Go, Node, Git and a separate database installation are not.

The bundle uses the exact published multi-platform image digest for Linux amd64 and arm64. Source remains available for contributors. Platform verification and deployment limitations are described in the installation guide; an image architecture alone is not a universal compatibility guarantee.

## Data and deployment boundaries

History is retained for seven days. Measurements are sampled, event replay is bounded, and logs are read from Docker rather than archived by Observatory. Missing observations remain explicit. This release is for trusted local development: no application authentication, no internet-facing deployment support and no production capacity guarantee. Docker socket access is powerful even with a read-only socket mount. Back up before upgrades; migrations are forward-only.

## Linux kernel advisory: CVE-2026-98432

This release does not fix the Linux kernel vulnerability. Go 1.24+ enables MPTCP listeners by default on Linux; Observatory currently uses the standard Go listener. Loopback-only host publication reduces external exposure but does not establish that the underlying kernel or container network is safe. Keep the host/Docker/WSL kernel on the applicable vendor-patched version. The Go Security Team warns that disabling MPTCP alone is an incomplete mitigation. No claim is made that this version is immune, and no kernel/system settings are changed by installation.

- [Go Security Team advisory](https://groups.google.com/g/golang-announce/c/PCoQcdxoScw/m/aD-MgXEvAAAJ)
- [Ubuntu kernel tracking](https://ubuntu.com/security/CVE-2026-98432)

## Report a vulnerability

Use the repository's private [Report a vulnerability](https://github.com/JoelJokyu/observatory-docker-monitor/security/advisories/new) flow. Do not post credentials, private logs or security-sensitive reproduction details in public issues. Ordinary bugs and feedback can use repository issues.
